You are the backend: in the CLI's manual mode a human answers each mind. This page runs exactly that flow.

Distinctness guard

The protocol requires distinct verdicts. Pairs that are identical (or ≥ 0.90 Jaccard-similar) are flagged and must be rewritten — same rule as the CLI.

Synthesis — you write the decision

The dissent field is mandatory: name the strongest minority view and who holds it. A synthesis without dissent is rejected.

This page is the manual-backend demo. The installable CLI adds ollama and openai-compat backends, per-mind model routing, and writes report.md + report.json to disk. 40/40 tests green.
